# Juegos diarios

App web (instalable en el móvil) para jugar con amigos a juegos diarios, registrar resultados,
ver rankings y chatear. Plan y decisiones en [`docs/PLAN.md`](docs/PLAN.md).

- **Web:** Vite + Svelte, publicada en GitHub Pages en cada push a `main`.
- **Datos:** Supabase. Esquema y reglas de seguridad en `supabase/migrations/`.

```bash
npm install
npm run dev
```
